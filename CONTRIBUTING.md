# Contributing to V100 Monitor

Thank you for considering a contribution!  Before you start, please read the following guidelines.

## Development workflow
1. Fork the repository and create a feature branch.
2. Write tests for any new functionality.
3. Run `make test` locally to ensure all checks pass.
4. Open a pull request and describe the changes.

## Coding style
* Follow PEP 8 (the linter in the CI will enforce this).
* Keep functions short and focused.
* Add docstrings to public classes and functions.
